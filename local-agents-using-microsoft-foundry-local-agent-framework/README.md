# Building Local-First Agents with Microsoft Foundry Local & Agent Framework

**Event:** PUG Tech Talk  
**Date:** 22th August 2026  
**Speaker:** Manish Lad  
**Location:** Pune

---

## Abstract

Most AI agents assume a network connection and a cloud bill. This session flips that — a real agent, built with Microsoft's Agent Framework, running entirely offline on a small Phi model via Foundry Local. We look at when local-first is genuinely the right product call, not just a novelty, then build and run one live.

## What's covered

- Where the local-first assumption breaks down, and where it holds
- Running a small Phi model locally with **Microsoft Foundry Local**
- Building an agent on **Microsoft Agent Framework** against a local model
- The product trade: capability vs. privacy, latency, predictable cost and offline reliability
- A live build and run — no network, no inference bill

## Who it's for

Developers and product folks working on AI agents, anyone weighing on-device against cloud inference, and people curious about small language models in production.
